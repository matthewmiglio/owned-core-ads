# owned-core-ads
Leverages undetectable chromedriver to quickly post to www.ownedcore.com


## instructions

### set creds
Use creds.py
Manually edit the if __name__ == 'main' block with your login(s)
Run the script

### set poster params
config make_ad_message() make_ad_title() to edit your post's content

### setup environment and run program
poetry install
select your new poetry environmen
poetry run python poster.py
